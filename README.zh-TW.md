# File Rename：用 PopClip 幫檔案改名

[English](README.md)

不想再對著 `IMG_1234.jpg` 想名字？File Rename 可以翻譯現有檔名，也能看圖片或影片，幫你取一個容易辨認的名字。原檔名可以是中文、日文或其他語言；這一版產生的新名字是英文。

反白幾個字 → 點圖示 → 看建議 → 按「套用」。 你可以先修改建議，按下套用才會更名。

## 兩個圖示，自己選怎麼取名

| 圖示 | 功能 | 例子 |
| --- | --- | --- |
| 語言：「譯檔名」 | 把原本的名稱翻成英文。 | `週末野餐照片.jpg` → `weekend-picnic-photo.jpg` |
| 掃描：「看內容命名」 | 看圖片或影片裡的內容，再取名字。 | 野餐照片 → `picnic-photo.jpg`；料理教學影片 → `cooking-tutorial.mp4` |

「看內容命名」只能在 Finder 裡使用。目前外掛的按鈕、預覽和提示都是繁體中文。

建議名稱使用 2～4 個單字，並以 32 個字元內為目標，保留主題和素材類型，例如 `command-key-icon.webp`。不必要的顏色、線條樣式和背景細節會省略。翻譯時仍以原名稱的意思為準，不會猜測檔案內容；套用前也可以自己修改、加上更多單字。

## 開始前需要什麼？

- 一台 Mac，並已安裝 [PopClip](https://www.popclip.app/) 2026.8.1 或更新版本。
- 自己的 Gemini API Key：這是 Google 提供的金鑰，讓外掛能使用 Gemini。可到 [Google AI Studio](https://aistudio.google.com/app/api-keys) 取得。
- 在 Finder 更改檔名，需要 Python 3.9 以上這個小工具。
- 如果要看影片取名，還需要 ffmpeg，用來從影片取出畫面。

這些工具不會由外掛自動安裝。[工具安裝方式](CONTRIBUTING.md#setup-tools)放在進階說明裡。如果只在其他 App 翻譯反白文字，並已在外掛設定填好 Key，就不需要上述兩個工具。

## 安裝

[下載 FileRename.popclipextz 安裝檔](https://github.com/chasehuang/file-rename/releases/latest/download/FileRename.popclipextz) · [查看更新說明](https://github.com/chasehuang/file-rename/releases/latest)

目前 repo 維持私人，請登入有存取權的 GitHub 帳號才能下載。之後公開 repo，這些連結可以繼續使用。

下載後：

1. 雙擊安裝檔，依 PopClip 的提示安裝。
2. 安裝時會看到「未簽署」提醒；這個安裝檔是本機製作的版本。
3. 在 PopClip 的外掛設定開啟「File Rename」，填入自己的 Gemini API Key。

Key 會存進這台 Mac 的鑰匙圈。如果想使用本機 `.env` 檔案，需要在設定中填入它的位置，外掛不會自行尋找。兩個欄位都留白時，會提醒你先設定 Key。這個選用方式請看[進階設定](CONTRIBUTING.md#local-credentials)。

如果你下載的是原始碼，請看[製作安裝檔的方法](CONTRIBUTING.md#tests-and-build)。

## 幫 Finder 裡的檔案改名

1. 選取一個檔案，按 Return，讓檔名變成可以編輯的狀態。
2. 用滑鼠反白檔名的任意一段，叫出 PopClip。
3. 點語言圖示翻譯檔名，或點掃描圖示看內容取名。
4. 看過建議後，可以修改，再按「套用」。按「取消」就不改名。

例如 `週末野餐照片.jpg`，只反白「野餐」就可以。外掛仍會翻譯完整名稱，變成像 `weekend-picnic-photo.jpg` 這樣的檔名，不需要每次都反白全部。日文也可以，例如 `週末のピクニック.jpg` → `weekend-picnic.jpg`。

只按 Return 不會自動叫出 PopClip，還要用滑鼠反白文字。第一次使用時，Mac 可能會請你允許 PopClip 控制 Finder，才能讀取你選的檔案。

更名後，檔案留在原本的資料夾，`.jpg`、`.mp4` 這些檔名結尾也會保留。遇到同名檔案時，外掛會加上 `-2` 等數字，或請你重新操作，不會覆蓋其他檔案。如果你中途改選其他檔案，也會停止這次更名。

## 翻譯其他 App 裡的文字

在其他 App 反白一段文字，點語言圖示，就能產生英文檔名。

按下「套用」後，如果原本的位置可以輸入文字，就會直接換成英文檔名；如果不能輸入，就會複製到剪貼簿，讓你自行貼上。預覽會告訴你接下來會做哪一種操作。

## 哪些檔案可以用？

| 你想處理的內容 | 可以怎麼用 |
| --- | --- |
| 一般檔案的名稱 | 翻譯成英文，不需要讀取檔案內容。 |
| PNG、JPG／JPEG、WebP 圖片 | 看圖片取名；圖片大小上限約 14.7 MB。 |
| MP4、MOV、M4V、WebM、MKV 影片 | 取出最多 8 張畫面來判斷內容。 |
| PDF、Word、音樂或其他格式 | 可以翻譯檔名，目前不會閱讀文件或聽音訊。 |

一次只能處理一個檔案，還不能批量改名，也不能更改資料夾名稱。請選原始檔案，不要選連到別處的替身或捷徑。動畫圖片只看第一個畫面。

新名稱使用小寫英文字母、數字和 `-`。32 個字元的目標不包含 `.jpg` 等結尾；有必要時可以超過，最多 64 個字元。翻譯文字時，一次最多反白 2,000 個字元。

## 會把什麼傳給 Google？

Gemini 需要連網才能取名。 讀取檔案、處理圖片、取出影片畫面，以及最後更名，都在你的 Mac 上完成。

- 翻譯檔名：把檔案原本的名稱，或你反白的文字，傳給 Gemini 翻成英文檔名。
- 圖片命名：先移除圖片裡記錄的拍攝地點、日期等資訊，再讓 Gemini 看圖取英文檔名。原圖不會被修改。
- 影片命名：從影片取出最多 8 張畫面，讓 Gemini 看這些畫面取英文檔名，不會上傳整段影片或聲音。

外掛會在你的 Mac 上另外製作一份用來上傳的圖片，處理完就刪除這份本機副本。如果無法清除附加資訊，就停止上傳。圖片上直接看得見的人臉、地址或文字仍會傳給 Gemini，不會自動遮住。

點下圖示時，資料就會先傳給 Google，之後才出現建議。按「取消」可以取消改名，但不能撤回已傳送的資料。

使用 Gemini 3.1 Flash-Lite 會消耗你 Google 帳號的使用額度，可能產生費用。費用與資料使用方式請看 Google 的[價格說明](https://ai.google.dev/gemini-api/docs/pricing)和[服務條款](https://ai.google.dev/gemini-api/terms)。

## 遇到問題時

| 問題 | 可以怎麼做 |
| --- | --- |
| 按 Return 後沒有出現 PopClip | 再用滑鼠反白檔名中的幾個字。 |
| 提示找不到 Key | 在 PopClip 的「File Rename」設定貼上自己的 Gemini API Key。 |
| 無法取得 Finder 裡的檔案 | 確認只選一個檔案，並允許 PopClip 控制 Finder。 |
| 提示缺少 Python 或影片工具 | 依[工具安裝方式](CONTRIBUTING.md#setup-tools)補上。 |
| 圖片太大或無法處理 | 另存一張較小的 PNG 或 JPG 再試，或改用「譯檔名」。 |
| 提示檔案已變更或名稱重複 | 關閉預覽，重新選取檔案再試。 |
| 無法產生建議 | 檢查網路、Gemini Key 和 Google 帳號的使用額度。 |

## 翻譯一次大概多少錢？

以 2026-11-06 實測的 5 個中日文檔名來看，每次平均約 586 token、US$0.000162；翻譯 1,000 次約 US$0.16，US$1 大約能翻譯 6,000 次。

token 是 AI 計算文字份量的單位，不等於字數。送出的用量也包含外掛給 AI 的命名說明，不只是檔名那幾個字；這次平均送出約 574 token，收到約 12 token 的回覆。

以下於 2026-11-06 使用 Gemini 3.1 Flash-Lite，將每個範例各翻譯一次。當時還沒套用縮短檔名的新規則；只傳檔名，沒有傳檔案內容。

| 原本的檔名 | 送出 token | 回覆 token | 每次費用（美元） | US$1 約能翻譯幾次 |
| --- | ---: | ---: | ---: | ---: |
| `週末野餐照片.jpg` | 571 | 10 | US$0.00015775 | 6,339 |
| `週末のピクニック.jpg` | 572 | 8 | US$0.00015500 | 6,451 |
| `東京旅行住宿清單.xlsx` | 572 | 12 | US$0.00016100 | 6,211 |
| `家族で作る簡単な晩ごはんレシピ.docx` | 574 | 11 | US$0.00016000 | 6,250 |
| `2026年冬季家庭旅遊行程與交通預算整理.pdf` | 581 | 21 | US$0.00017675 | 5,657 |

費用按 [Google 當日的標準付費價格](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.1-flash-lite)試算：每 100 萬 token，送出 US$0.25、回覆 US$1.50。AI 的思考用量也算在回覆費用中；這 5 次沒有回報額外思考用量。

例如第一列：`571 × 0.25 ÷ 1,000,000 ＋ 10 × 1.50 ÷ 1,000,000 ＝ US$0.00015775`。每美元次數以未四捨五入的費用計算，再取整數；「約 6,000 次」則依 5 個範例的平均費用估算。

這是翻譯檔名的小樣本估算，不計免費額度或折扣，也不含稅。實際用量會隨檔名、回覆及外掛版本變動；免費額度內可能不收費。看圖片、影片取名不適用這張表，因為還要計算傳送畫面的用量。
