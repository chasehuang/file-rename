- Remove bold-markup asterisks from the English and Traditional Chinese documentation so labels display as plain text.
- 移除中英文說明中的粗體星號標記，讓文字直接顯示，不再露出星號。

## 0.1.0 - 2026-11-08

- First File Rename release, with English and Traditional Chinese guides and a ready-to-install PopClip package.
- Translate filenames or selected words, or suggest names from pictures and sampled video frames using Gemini 3.1 Flash-Lite.
- Suggest English names with 2–4 words, aiming for 32 characters, and let users edit the preview before applying.
- Support partial filename selections in Finder, preserve file extensions and prevent overwriting another file.
- Prepare upload copies with extra image details removed, without changing the original files.
- Store a Gemini API Key in the local Mac Keychain, or read a specific `.env` file chosen in the settings.

- File Rename 首次發布，提供中英文說明與可直接安裝的 PopClip 外掛。
- 使用 Gemini 3.1 Flash-Lite 翻譯檔名或反白文字，也能看圖片、影片抽樣畫面取名。
- 建議名稱使用 2～4 個英文單字，以 32 個字元內為目標；先預覽、修改，再按「套用」。
- 在 Finder 只需反白部分檔名，保留副檔名，也不會覆蓋其他檔案。
- 另外製作用來上傳的圖片並移除附加資訊，原始檔案不會被修改。
- Gemini API Key 存在本機鑰匙圈，也可在設定中自行指定 `.env` 檔案。
